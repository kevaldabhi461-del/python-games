# 🏓 Paddle Game

A simple and fun Paddle Game built using Python. Control the paddle, bounce the ball, and try to keep it in play as long as possible. This project was created to practice game development concepts such as collision detection, event handling, animation, and game loops in Python.

## 🚀 Features

- Smooth paddle movement
- Ball physics and bouncing mechanics
- Collision detection
- Score tracking
- Simple and interactive gameplay
- Beginner-friendly Python project

## 🛠️ Technologies Used

- Python 3
- Turtle / Pygame (update according to your project)
- Object-Oriented Programming Concepts

## 📦 Installation

1. Clone the repository:

```bash
git clone https://github.com/kevaldabhi461-del/python-games-.git
```

2. Navigate to the project folder:

```bash
cd python-games-/paddle\ game
```

3. Install required dependencies (if using Pygame):

```bash
pip install pygame
```

## ▶️ Run the Game

```bash
python main.py
```

> Replace `main.py` with your actual Python file name.

## 🎮 Controls

| Key | Action |
|------|---------|
| Left Arrow | Move Paddle Left |
| Right Arrow | Move Paddle Right |
| ESC | Exit Game |

> Update controls according to your implementation.

# 🐍 Snake Game

A classic Snake Game built in Python. Control the snake, collect food, grow longer, and try to achieve the highest score without colliding with the walls or yourself.

## 📌 Features

- Smooth snake movement
- Food spawning at random locations
- Score tracking
- Snake grows after eating food
- Collision detection
- Game Over screen
- Simple and beginner-friendly implementation

## 🛠 Technologies Used

- Python 3
- Turtle Graphics

## 📂 Project Structure

```text
├── main.py
├── snake.py
├── food.py
├── scoreboard.py
└── README.md
```

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/kevaldabhi461-del/python-games-.git
```

2. Navigate to the Snake Game folder:

```bash
cd python-games-/snack game
```

3. Run the game:

```bash
python main.py
```

## 🎮 Controls

| Key | Action |
|------|---------|
| ↑ | Move Up |
| ↓ | Move Down |
| ← | Move Left |
| → | Move Right |

## 🎯 Objective

- Eat the food to increase your score.
- Each food item makes the snake grow longer.
- Avoid hitting the wall.
- Avoid colliding with your own body.
- Try to achieve the highest score possible.
